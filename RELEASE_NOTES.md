# Forge language servers 0.2.0

Includes a Linux x86-64 native server, an installable TypeScript server archive and SHA-256 checksums. Install the Forge compiler separately.

The new doctor command checks a fixed sample program and the stdio protocol connection. Compiler failures now produce actionable diagnostics even when stderr is unfamiliar. The TypeScript server uses explicitly configured tools or PATH rather than executing a workspace-local compiler implicitly.

See the README for installation and VS Code, Sublime Text and Neovim clients.
